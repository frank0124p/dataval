# PLM｜生命週期階段（語意）

## 目的
PLM 的本質是管理產品 / 料件從概念、設計、量產到淘汰（EOL）的生命週期
階段。資料模型應能正確表達當前階段與階段轉移，否則無法支撐生命週期治理。

## 適用情境
承載產品 / 料件狀態、生命週期階段的表（part、product、
lifecycle_status 等）。

## 違反後果
階段語意不清會使「哪些料件可用於新設計」「哪些已淘汰」無法判斷，
影響採購與設計決策。需語意判斷，設為**只提示**。

## 卡控
```check-llm
這是與 PLM 生命週期階段相關的 schema。請從生命週期治理語意檢視：
- 是否有表達生命週期階段的欄位（如 lifecycle_stage / status：
  概念、設計、量產、停產、淘汰 EOL 等）？
- 階段值是否為受控的有限集合（而非自由文字），以利一致判斷？
- 是否能追溯階段轉移的時間（何時進入量產、何時 EOL）？
- 是否與版次、有效日期協同，避免狀態彼此矛盾？
針對每個疑慮，指出相關的表或欄位，以「給設計者思考的提問」語氣描述。
```
