# FCM｜主檔語意一致性

## 目的
FCM 領域的主檔資料需要語意層面的一致性檢視，這部分規則無法機械判斷，
交由模型輔助。

## 適用情境
FCM 領域的主檔與關聯表。

## 違反後果
語意不一致會增加跨系統整合風險，但非硬性錯誤，設為**只提示**。

## 卡控
```check-llm
這是 FCM 領域的 schema。請從主檔治理語意檢視：
- 主檔實體是否有清楚的唯一識別與權威來源？
- 是否存在跨表重複承載同一主檔屬性的風險？
針對每個疑慮指出相關的表或欄位，以提問語氣描述。
```
