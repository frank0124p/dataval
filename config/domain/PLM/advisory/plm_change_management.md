# PLM｜工程變更管理（語意）

## 目的
工程變更（ECN / ECO）是 PLM 的核心流程：任何對料件或 BOM 的變更
都應可追溯到一筆變更紀錄，並關聯到受影響的對象與生效版本。

## 適用情境
承載變更單、變更影響、變更與料件 / BOM 關聯的表（ecn、eco、
change_request、change_affected_item 等）。

## 違反後果
變更無法追溯會破壞 PLM 的稽核性與可追溯性，無法回答「為什麼這個
料件變成這樣」。需語意判斷，設為**只提示**。

## 卡控
```check-llm
這是與 PLM 工程變更（ECN/ECO）相關的 schema。請從變更可追溯性語意檢視：
- 是否有明確的變更單實體（change / ecn / eco）作為變更的單一真實源？
- 變更是否能關聯到「受影響的料件 / BOM」與「變更前後的版次」？
- 是否能追溯變更的時間、原因、狀態（提出、審核、生效）？
- 料件 / BOM 的變更是否強制經由變更單，而非直接覆寫（保留稽核軌跡）？
針對每個疑慮，指出相關的表或欄位，以「給設計者思考的提問」語氣描述。
```
