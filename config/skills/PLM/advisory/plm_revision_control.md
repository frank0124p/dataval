# PLM｜版次與版本控制（語意）

## 目的
PLM 中，料件與文件會歷經多次版次（revision）。正確的版次模型必須能
回答「某時間點的有效版本是哪一個」「舊版是否保留可追溯」。這是 PLM
有別於一般主檔的關鍵語意。

## 適用情境
承載料件、產品、工程文件且具版本概念的表（part、document、
product_master、ecn 等）。

## 違反後果
版次模型不當會導致無法追溯歷史、無法判斷生效版本，違反 PLM 的
可追溯性要求。需語意判斷，設為**只提示**。

## 卡控
```check-llm
這是與 PLM 版次控制相關的 schema。請從版本治理語意檢視：
- 是否有明確的版次 / 版本欄位（revision / version）？
- 是否能表達「生效版本」與「歷史版本」的區別（例如有效日期區間、
  是否為當前版本的標記）？
- 主鍵設計是否允許同一料件存在多個版次（而非覆寫舊版）？
- 是否能避免版本資訊散落多表造成的不一致？
針對每個疑慮，指出相關的表或欄位，以「給設計者思考的提問」語氣描述。
```
