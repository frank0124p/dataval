# 跨表命名語意一致性（語意）

## 目的
規則能查字形，查不了語意。縮寫不一致、同概念異名、欄名與型別語意不符，需要理解。

## 適用情境
整個 schema 的跨表比對。

## 違反後果
理解成本與誤用風險上升，非硬性錯誤。只提示。

## 卡控
```check-llm
請檢視整個 schema，找出規則無法機械判斷的命名語意問題：
- 縮寫不一致（cust 與 customer 並存）
- 同一概念在不同表使用不同名稱（user_id 與 member_id 指同一實體）
- 欄位名稱與其型別或註解語意不符
對每個發現指出表或欄位，以「給設計者思考的提問」語氣描述。
```
